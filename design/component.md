# Klino Component System

## Purpose

Define reusable interface components used throughout the Klino website and future applications.

Components should be:

- Simple
- Consistent
- Accessible
- Easy to use

---

# 1. Buttons

## Primary Button

Purpose:

Main actions.

Examples:

- Book Cleaning
- Continue
- Confirm Booking
- Pay Now

Style:

- Klino primary color
- Rounded corners
- Clear text
- Strong visibility

---

## Secondary Button

Purpose:

Alternative actions.

Examples:

- Learn More
- Cancel
- Go Back

Style:

- Light background
- Clear border
- Less emphasis than primary button

---

## Danger Button

Purpose:

Actions requiring caution.

Examples:

- Delete Account
- Cancel Booking

Style:

- Warning appearance
- Clear confirmation required

---

# 2. Navigation Bar

Purpose:

Help users move around the platform.

Contains:

- Klino logo
- Main menu
- Profile icon
- Notifications

Customer navigation:

- Home
- Book Cleaning
- Bookings
- Profile

Agent navigation:

- Dashboard
- Jobs
- Earnings
- Profile

---

# 3. Cards

Cards display grouped information.

Examples:

- Service cards
- Agent cards
- Booking cards
- Payment cards

Card structure:

- Image/Icon
- Title
- Description
- Action button

---

# 4. Service Card

Used for cleaning services.

Contains:

- Service image
- Service name
- Short description
- Starting price
- Select button

Example:

Deep Cleaning

"Detailed cleaning for kitchens, bathrooms, and living spaces."

[Choose]

---

# 5. Agent Profile Card

Used when showing cleaners.

Contains:

- Profile photo
- Name
- Verification badge
- Rating
- Experience
- Location

Example:

Verified Agent ✅

Rating: ★★★★★

---

# 6. Booking Card

Shows booking information.

Contains:

- Service type
- Date
- Time
- Agent
- Status

Status examples:

Pending

Accepted

In Progress

Completed

Cancelled

---

# 7. Form Components

Used for:

- Sign up
- Login
- Booking
- Verification

Rules:

- Clear labels
- Helpful instructions
- Error messages
- Simple inputs

---

# 8. Status Badges

Used to quickly communicate information.

Examples:

Verified

Pending

Completed

Cancelled

---

# 9. Alerts

Used for important messages.

Examples:

Success:

"Your booking has been confirmed."

Warning:

"Your agent verification is pending."

Error:

"Payment could not be completed."

---

# 10. Loading States

When the system is processing:

Examples:

- Uploading photos
- Processing payment
- Finding an agent

The user should always know something is happening.
