# Klino Brand Colors

## Purpose

Define the official colors used across the Klino website and future mobile applications.

---

# Primary Color

## Klino Blue

Purpose:
- Main brand color
- Primary buttons
- Navigation
- Important actions

Emotion:
- Trust
- Security
- Professionalism

---

# Secondary Color

## Clean Green

Purpose:
- Success messages
- Verification badges
- Completed bookings

Emotion:
- Freshness
- Cleanliness
- Growth

---

# Neutral Colors

## White

Usage:
- Main backgrounds
- Cards
- Clean spaces

## Dark Gray

Usage:
- Main text
- Headings

## Light Gray

Usage:
- Borders
- Secondary backgrounds
- Disabled elements

---

# Status Colors

## Verified

Green

Used for:
- Verified agents
- Approved accounts

## Pending

Orange

Used for:
- Waiting approvals
- Processing states

## Error

Red

Used for:
- Failed payments
- Cancelled bookings
- Warnings
