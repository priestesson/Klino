# Klino Design System

## Purpose

The Klino design system defines the visual style, components, and user experience rules for the Klino platform.

The goal is to create a brand that feels:

- Trustworthy
- Professional
- Safe
- Modern
- Simple

---

# 1. Brand Identity

## Brand Name

Klino

## Brand Personality

Klino should feel like:

- A trusted professional
- A helpful assistant
- A secure marketplace
- A premium home service company

---

# 2. Brand Colors

## Primary Color

Name:
Klino Blue

Purpose:

Used for:
- Main buttons
- Navigation
- Important actions
- Brand identity

Feeling:

- Trust
- Security
- Reliability


## Secondary Color

Name:
Clean Green

Purpose:

Used for:
- Success messages
- Verification badges
- Completed jobs

Feeling:

- Freshness
- Cleanliness
- Growth


## Neutral Colors

White:
- Backgrounds
- Cards

Dark Gray:
- Main text

Light Gray:
- Borders
- Secondary backgrounds

---

# 3. Typography

## Main Font

Use:

Modern sans-serif fonts

Examples:

- Inter
- Roboto
- Poppins

Purpose:

Easy reading and modern appearance.

---

# 4. Logo Usage

The Klino logo should appear:

- Top left on website
- Login pages
- Customer dashboard
- Agent dashboard

Logo should have:

- Clear space around it
- No distortion
- Consistent size

---

# 5. Buttons

## Primary Button

Used for important actions.

Examples:

- Book Cleaning
- Continue
- Confirm Payment


Style:

- Rounded corners
- Clear text
- Strong contrast


## Secondary Button

Used for alternative actions.

Examples:

- Cancel
- Go Back
- Learn More

---

# 6. Cards

Cards are used for displaying information.

Examples:

- Cleaning services
- Agent profiles
- Booking details
- Payments

Card style:

- Rounded edges
- Simple shadows
- Clean spacing

---

# 7. Forms

All forms should have:

- Clear labels
- Simple inputs
- Helpful error messages
- Progress indicators when needed

Examples:

- Sign up
- Booking form
- Agent verification

---

# 8. Icons

Icon style:

- Simple
- Modern
- Easy to understand

Examples:

Profile:
Person icon

Booking:
Calendar icon

Payment:
Wallet icon

Verification:
Shield icon

---

# 9. Status Colors

Verified:
Green

Pending:
Orange

Cancelled:
Red

Completed:
Blue/Green

---

# 10. User Experience Principles

## Trust First

Always show:

- Verification information
- Security messages
- Clear pricing

## Simple Actions

Users should not need many steps.

## Transparency

Always show:

- Booking status
- Payment status
- Agent information

## Safety

Highlight:

- Verified agents
- Reviews
- Protection system
