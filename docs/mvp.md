# Klino MVP (Version 1)

## Goal

Launch a simple, reliable platform that allows customers to book verified cleaning professionals.

---

## Customer Features

- Create account
- Log in
- Edit profile
- Book a cleaning
- Upload property photos
- View booking status
- Receive agent details
- Confirm job completion
- Rate and review agent

---

## Agent Features

- Create account
- Upload verification documents
- Receive booking requests
- Accept or decline jobs
- Upload before photos
- Upload after photos
- Mark job as complete
- View earnings

---

## Admin Features

- View all customers
- View all agents
- Approve agent registrations
- View bookings
- Manage disputes
- View payments

---

## Payments

- Customer paymen
- Secure payment holding
- Payment release after customer confirmation

---

## Notifications

- Booking confirmation
- Agent assigned
- Job started
- Job completed
- Payment confirmation
